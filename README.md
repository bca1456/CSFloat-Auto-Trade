# CSFloat Auto Trade

Автоматический приём торговых предложений CSFloat и отправка предметов через Steam.
Бот периодически проверяет CSFloat, принимает входящие сделки и создаёт Steam trade offer
на отправку предмета покупателю, а подтверждение через Steam Guard выполняет ASF.

> Версии зависимостей зафиксированы в `requirements.txt`, в том числе `aiosteampy==0.7.20`,
> под которую подогнаны внутренние патчи. При обновлении `aiosteampy` патчи могут перестать
> применяться — бот сообщит об этом в логе.

## 1. Клонирование репозитория

Откройте терминал (Командную строку или PowerShell на Windows) и выполните:

```bash
git clone https://github.com/bca1456/CSFloat-Auto-Trade.git
cd CSFloat-Auto-Trade
```

## 2. Установка зависимостей

Убедитесь, что находитесь в папке проекта и активировали виртуальное окружение. Затем установите зависимости из `requirements.txt`:

```bash
pip install -r requirements.txt
```

На Windows можно запустить `run_csfloat_auto_trade.bat` — он сам проверит Python, установит
недостающие зависимости и запустит скрипт.

## 3. Конфигурация скрипта

Создайте или отредактируйте файл `steam.json` в корне проекта (шаблон — `steam.example.json`).
Укажите в нём:

- `csfloat_api_key` — API-ключ CSFloat.
- `steam_api_key` — API-ключ Steam.
- `steam_id64` — ваш Steam ID64, например `76561198034388123`.
- `steam_login` — логин Steam.
- `steam_password` — пароль Steam.
- `shared_secret` и `identity_secret` — секреты для подтверждения торговых предложений. Их можно получить из maFile.

**Важно:** не делитесь ключами и секретами. Храните их в безопасном месте. Все секретные файлы
(`steam.json`, `asf.json`, `tg.json`, `cookies.json`) добавлены в `.gitignore`.

### Telegram-уведомления (необязательно)

Создайте `tg.json` (шаблон — `tg.example.json`), чтобы получать уведомления о старте бота,
отправленных офферах и проблемах с авторизацией:

```json
{
  "bot_token": "ТОКЕН_БОТА",
  "chat_id": "ВАШ_CHAT_ID"
}
```

Если файла нет — уведомления просто не отправляются.

## 4. Настройка и запуск ArchiSteamFarm (ASF)

Скрипт использует ASF для подтверждения торговых предложений. ASF должен быть запущен и авторизован под тем же Steam-аккаунтом, который указан в `steam.json`.

1. Скачайте подходящую сборку ASF с [официальной страницы загрузок](https://github.com/JustArchiNET/ArchiSteamFarm/releases) и распакуйте её в отдельную папку.
2. Запустите ASF один раз, чтобы он создал необходимые файлы, затем остановите его.
3. Создайте конфигурацию бота в папке `config`, следуя [официальной документации ASF](https://github.com/JustArchiNET/ArchiSteamFarm/wiki/Configuration). Укажите логин Steam. Пароль можно не сохранять в конфигурации и вводить при запросе ASF.
4. Включите IPC в глобальной конфигурации ASF (`IPC: true`) и задайте пароль IPC в параметре `IPCHost`. Сохраните пароль: он понадобится на следующем шаге.
5. Запустите ASF и завершите вход в аккаунт, включая подтверждение Steam Guard, если оно потребуется.
6. Создайте `asf.json` в корне проекта (шаблон — `asf.example.json`):

   ```json
   {
     "api_url": "http://localhost:1242",
     "password": "YOUR_ASF_IPC_PASSWORD",
     "bot_name": "имя_бота_из_ASF"
   }
   ```

   Замените `YOUR_ASF_IPC_PASSWORD` на пароль IPC из конфигурации ASF, а `имя_бота_из_ASF` — на имя конфигурации бота. Если `bot_name` не указан, скрипт выберет активного бота ASF автоматически. Если ASF запущен на другом компьютере, укажите его адрес вместо `localhost` и настройте доступ к IPC.
7. Оставив ASF запущенным, запустите скрипт из корня проекта:

   ```bash
   python CSFloat_Auto_Trade.py
   ```

Файл `asf.json` добавлен в `.gitignore`, поэтому пароль IPC не попадёт в Git. Не открывайте IPC в публичный интернет.

## 5. Запуск скрипта

Если ASF настроен и работает, скрипт можно запустить из корня проекта командой:

```bash
python CSFloat_Auto_Trade.py
```

Поведение по умолчанию:

- Скрипт проверяет новые торговые предложения **каждые 30 минут** (`CHECK_INTERVAL_MINUTES`).
- Все паузы между запросами к Steam содержат случайный разброс (jitter), чтобы не долбить
  сервис ровным ритмом.
- При временной недоступности Steam или ошибке авторизации бот не падает, а перелогинивается
  и повторяет попытку с нарастающей паузой.

### Логи

Вывод идёт одновременно в консоль и в файл `csfloat_auto_trade.log` (ротация: до 5 файлов
по 5 МБ). Формат строки: `дата время [УРОВЕНЬ] сообщение`.

### Служебные файлы

Рядом со скриптом создаются файлы состояния (не удаляйте их вручную без необходимости):

- `cookies.json` — cookies Steam-сессии.
- `processed_trades.json` — обработанные сделки (хранятся 30 дней).
- `seller_sent_pending_verification.json` — сделки, ожидающие статуса `verified`.
- `buyer_purchases_log.json` — журнал покупок.
- `steam_rate_limit.json` / `steam_auth_backoff.json` — активные паузы после лимитов Steam.

## 6. Безопасность

- Никогда не публикуйте `steam.json`, `cookies.json`, `asf.json`, `tg.json` и содержимое maFile.
- Не выставляйте IPC ASF в публичный интернет.
- Соблюдайте разумные интервалы между операциями — частые ошибки и ретраи могут привести к
  временным ограничениям Steam.
