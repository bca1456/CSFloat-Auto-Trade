## Шаг 1: Клонирование репозитория

Сначала склонируйте репозиторий с GitHub на ваш локальный компьютер.

1.  **Откройте терминал (Командную строку или PowerShell на Windows).**
   
2.  **Выполните команду:**
       
    git clone https://github.com/bca1456/CSFloat-Auto-Trade.git
           
3.  **Перейдите в директорию проекта:**
           
    cd CSFloat-Auto-Trade
     

## Шаг 2: Установка зависимостей

Установите необходимые пакеты, перечисленные в файле requirements.txt.

1.  **Убедитесь, что находитесь в директории проекта и активировано виртуальное окружение.**
   
2.  **Выполните команду:**
     
    pip install -r requirements.txt
     

## Шаг 3: Конфигурация скрипта

Перед запуском скрипта необходимо настроить конфигурационный файл steam.json.

 -  **Отредактируйте файл `steam.json` в корне проекта.**
   
 -  **Добавьте в него следующие параметры:**
           
    -   csfloat_api_key: Ваш API-ключ от CSFloat.
    -   steam_api_key: Ваш Steam API-ключ.
    -   steam_id64: Ваш Steam ID64 (например, 76561198034388123).
    -   steam_login: Ваш логин от Steam.
    -   steam_password: Ваш пароль от Steam.
    -   shared_secret и identity_secret: Секреты, необходимые для подтверждения торговых предложений. Их можно получить из maFile.
   
    **Важно:** Никогда не делитесь этими ключами и секретами. Храните их в безопасном месте.
   

## Шаг 4: Запуск скрипта

Теперь вы готовы запустить скрипт.
   
1.  **Выполните команду:**
     
    python CSFloat_Auto_Trade.py
     
2.  **Скрипт начнёт выполнение и будет проверять наличие новых торговых предложений каждые 5 минут (по умолчанию).**

## Запуск ArchiSteamFarm (ASF)

Скрипт использует ASF для подтверждения торговых предложений Steam. ASF должен быть запущен и авторизован под тем же Steam-аккаунтом, для которого настроен steam.json.

1. Скачайте подходящую сборку ArchiSteamFarm с [официальной страницы загрузок](https://github.com/JustArchiNET/ArchiSteamFarm/releases) и распакуйте её в отдельную папку.
2. Запустите ASF один раз, чтобы он создал необходимые файлы, затем остановите его.
3. Создайте конфигурацию бота ASF в папке config согласно [официальной документации ASF](https://github.com/JustArchiNET/ArchiSteamFarm/wiki/Configuration). Укажите логин Steam; пароль можно не сохранять в конфигурации и вводить при запросе ASF.
4. Включите IPC в глобальной конфигурации ASF (IPC: true) и задайте пароль IPC ( 보). Замените YOUR_ASF_IPC_PASSWORD ниже на тот же пароль. Не публикуйте его.
5. Запустите ASF и завершите вход в аккаунт, включая подтверждение Steam Guard, если оно потребуется.
6. В корне этого проекта создайте asf.json:

   ```json
   {
     "api_url": "http://localhost:1242",
     "password": "YOUR_ASF_IPC_PASSWORD",
     "bot_name": "имя_бота_из_ASF"
   }
   ```

   `bot_name` должен совпадать с именем конфигурации бота ASF. Если указать его, скрипт будет адресовать команды этому боту; без него ASF выберет активного бота автоматически. Для ASF на другом компьютере замените localhost на адрес этого компьютера и настройте доступ к IPC.
7. Оставив ASF запущенным, запустите скрипт из корня проекта командой python CSFloat_Auto_Trade.py.

Файл asf.json добавлен в .gitignore, поэтому пароль IPC не попадёт в Git. Не открывайте IPC в публичный интернет.
